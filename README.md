# Harness Builder

Claude Code / Codex 用のハーネス（指示ファイル・スキル・サブエージェント・権限設定）を、資料とヒアリングから生成する Chrome / Edge 拡張機能です。バージョン 0.1.0（MVP）。

## フォルダ構成

```
harness-builder-0.1.0/
├── extension/                 ← ブラウザに読み込むのはこのフォルダ
├── dev/                       ← テスト（拡張機能には含めない）
├── team-settings.sample.json  ← チーム設定ファイルのひな形
└── README.md
```

## インストール

ストアは使わず、「パッケージ化されていない拡張機能」として読み込みます。

**Google Chrome**

1. アドレスバーに `chrome://extensions` と入力して開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension` フォルダを選ぶ
4. ツールバーのパズルのアイコンから Harness Builder をピン留めしておくと便利です

**Microsoft Edge**

1. アドレスバーに `edge://extensions` と入力して開く
2. 左側の「開発者モード」をオンにする
3. 「展開して読み込み」を押し、`extension` フォルダを選ぶ

`extension` フォルダは読み込んだ後も削除・移動しないでください（ブラウザはその場所のファイルを使い続けます）。

## 初期設定

1. ツールバーの Harness Builder アイコンを押すと、サイドパネルが開きます。上部の「設定」を押します。
2. **チーム設定ファイル**を受け取っている場合は「チーム設定ファイルを読み込む」で読み込みます。LiteLLM の接続先と使用モデルが自動で入ります。
3. **LiteLLM の接続先**に API キーを入力して「保存」を押します。接続先へのアクセス許可を求められたら許可してください。
4. 「接続テスト」で、応答が返ることを確認します。
5. 許可リストがある場合は「許可リストのサイトへのアクセスを許可」を押します（サイドパネルの「このページを取り込む」に必要です）。

## 使い方

サイドパネルで、次の順に進みます。

| 手順 | 内容 |
| --- | --- |
| 1. 種類 | 業務特化 / 汎用、開発 / 非開発、出力先（Claude Code・Codex）を選ぶ |
| 2. ヒアリング | 目的・成果物・使用技術・慎重さのレベルなど（空欄でも可） |
| 3. 資料（業務特化のみ） | ファイル・フォルダ・閲覧中のページ・貼り付けで取り込む。取り込むと自動で解析し、充足度を表示 |
| 4. 不足の確認（業務特化のみ） | 足りない項目について、3〜5問の補完ヒアリングに答える |
| 5. 生成 | 概算トークンを確認して生成。汎用は「テンプレートだけで作る」（LLMなし）も可 |
| 6. 確認・出力 | ファイルを確認・直接編集し、zip ダウンロードまたはプロジェクトフォルダへ書き込み |

**資料の取り込み方法**

- ファイル: PDF、Word、Excel / CSV、PowerPoint（本文・発表者ノート・図）、テキスト / Markdown、ソースコード（SQL・Python など）、画像
- フォルダ: ソースコード一式。`.gitignore`・依存フォルダ・バイナリ・機密ファイル（`.env`、鍵ファイルなど）は自動で除外し、構成ファイルと代表的なソースを選んだ状態で確認画面を出します。件数の上限はありません
- 閲覧中のページ: 右クリック →「このページをハーネス資料に追加」「選択範囲を…」「この画像を…」。サイドパネルの「このページを取り込む」も使えます
- 貼り付け: メモやチャットの内容を直接貼り付け

認証情報（パスワード、API キー、トークン、接続文字列）らしき文字列は、取り込み時に自動でマスクします。個人情報（メールアドレス、電話番号）は警告を出し、「個人情報をマスク」で消せます。

作業中の内容はブラウザ内に保存されるので、パネルを閉じても続きから再開できます。広い画面で作業したいときは「タブで開く」を押してください。

## 生成されるファイル

| 出力先 | ファイル |
| --- | --- |
| Claude Code | `CLAUDE.md`、`.claude/skills/<名前>/SKILL.md`、`.claude/agents/<名前>.md`、`.claude/settings.json` |
| Codex | `AGENTS.md`、`.agents/skills/<名前>/SKILL.md`、`.codex/config.toml` |
| 共通 | `.harness/harness.ir.json`（中間表現）、`.harness/build-info.json`（生成時の入力）、`.harness/team-settings.json`、`.harness/README.md` |

- プロジェクトのルートにそのまま置いてください。Git にコミットするか、Box で共有します。
- Codex の `.codex/config.toml` は、そのプロジェクトを Codex で「信頼済み」にしたときだけ読み込まれます。
- Codex の設定ではファイル単位の禁止を指定できないため、禁止パスは `AGENTS.md` の「禁止事項」に書いています。
- フォルダへ書き込むとき、既存のファイルは `.bak-日時` を付けて残します。

## チーム設定ファイル

`team-settings.sample.json` を元に作り、完成したハーネスと同じ場所（Git または Box）で管理してください。API キーは含めません。

| 項目 | 内容 |
| --- | --- |
| `teamName` | チーム名（画面に表示） |
| `litellm.baseUrl` | LiteLLM のエンドポイント |
| `litellm.models.generate` | ハーネス本体の生成に使うモデル |
| `litellm.models.classify` | 資料の要点抽出に使うモデル（空なら generate） |
| `litellm.models.vision` | 画像の読み取りに使うモデル（空なら generate） |
| `allowedDomains` | ページを取り込んでよいサイト。`*.example.com` の形も可。空なら制限なし |
| `commonRules` | 生成するすべてのハーネスに必ず入れるルール |
| `forbiddenPaths` | 必ず読み書きを禁止するパス（Claude Code の権限設定と、両ツールの禁止事項に入る） |
| `defaultTargets` | 既定の出力先（`claude`、`codex`） |
| `outputLanguage` | 生成するハーネスの言語（`ja` / `en`） |

## 更新のしかた

1. 設定画面の「設定のバックアップ」で**エクスポート**する（念のため）
2. 新しい `extension` フォルダの中身を、今の `extension` フォルダに**上書き**する
3. 拡張機能の管理画面（`chrome://extensions` / `edge://extensions`）で Harness Builder の再読み込みボタンを押す

拡張機能をいったん削除して読み込み直すと、設定・資料・生成履歴が消えます。その場合はバックアップを**インポート**してください。

## Claude Code / Codex の仕様が変わったとき

ファイルの配置先や権限の対応は `extension/templates/targets.json` にまとめてあります。仕様が変わったら、このファイルを書き換えて拡張機能を再読み込みしてください（コードの修正は不要です）。

## 制約（MVP）

- 出力範囲はプロジェクト単位のみ（ユーザー全体の `~/.claude`、`~/.codex` は次期）
- 既存ハーネスの読み込みと更新、操作記録からの手順スキル生成、「これ覚えて」メモは次期
- フック（hooks）と MCP 設定は生成しません
- スキャンされた PDF（文字が埋め込まれていないもの）は文字を読めません。ページを画像として取り込んでください

## 開発者向け

```
cd dev
npm install
npm test
```

ブラウザ API をモックし、LiteLLM の応答もモックにして、資料の解析から生成・出力までを通して確認します（ライブラリ 35件、画面操作 11件、設定画面・ページ取り込み 9件）。

| ファイル | 役割 |
| --- | --- |
| `lib/extract.js`、`lib/codebase.js` | 資料・フォルダの解析 |
| `lib/secrets.js` | 機密情報の検出とマスク |
| `lib/checklist.js` | 資料チェックリストと充足度 |
| `lib/prompts.js`、`lib/pipeline.js` | LLM への指示と生成の流れ |
| `lib/ir.js` | 中間表現の定義と正規化 |
| `lib/adapters.js`、`templates/targets.json` | 中間表現から各ツールのファイルへの変換 |
| `lib/validate.js` | 出力前の検証 |
| `lib/templates.js` | 汎用ハーネスのテンプレート |
| `ui/sidepanel.js`、`ui/options.js`、`background.js` | 画面と右クリック取り込み |
